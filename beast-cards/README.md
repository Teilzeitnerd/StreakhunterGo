# Beast-Karten (SD-Karte einrichten)

Jedes Beast lebt auf einer eigenen microSD-Karte. Die Datei muss im
**Stammverzeichnis** der Karte liegen und genau `beast.shb` heißen:

```
SD-Karte (Stamm)
└── beast.shb
```

So geht's:

1. microSD-Karte als **FAT32** formatieren.
2. Aus dem gewünschten Ordner (RUGA, PINTAN, FEARO, LEONA, LURCO, GRELO)
   die Datei `beast.shb` in das **oberste** Verzeichnis der Karte kopieren.
3. Karte ins Gerät stecken. Das Beast erscheint auf dem Podest.

Alle sechs Dateien heißen gleich (`beast.shb`) und unterscheiden sich nur im
Inhalt. Die Ordner dienen nur dazu, sie auseinanderzuhalten. Pro Karte gehört
genau **eine** `beast.shb`.

Ohne Karte geht das Gerät in den Urlaubsmodus und das Beast nimmt keinen Schaden.
